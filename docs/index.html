Cómo instalarla

Hazlo con calma, en este orden. Solo la primera vez es un poco larga.

  1. Descarga el archivoToca el botón violeta de arriba. Si el teléfono pregunta «¿Quieres descargar este tipo de archivo?», toca Descargar o Aceptar.
  2. ÁbreloCuando termine, toca el aviso «Descarga completada» o abre la carpeta Descargas y toca el archivo dones-demo.apk.
  3. Permite instalar desde aquíAndroid te avisará que, por seguridad, no deja instalar apps de esta fuente. Toca Configuración y activa Permitir de esta fuente. Es una sola vez y solo para este navegador.
  4. Toca «Instalar»Vuelve atrás con la flecha y toca Instalar. Si aparece «Play Protect», toca Instalar de todos modos: es normal con apps que no vienen de la tienda.
  5. Abre «Llamados»Toca Abrir, o busca el ícono «Llamados» en tu pantalla. Elige tu nombre o crea tu perfil y empieza.
